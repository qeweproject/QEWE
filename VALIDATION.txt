Release verification:
The build uses ASAR-only loading/integrity validation and disables Node-mode,
NODE_OPTIONS and inspector environment/CLI fuses. npm run verify:release reads
these bits in the packaged Windows EXE and compares every app file with the
source. This command must succeed before distributing the installer.

Limits:
No real funds, user seeds or production wallets used. No Windows 11 execution,
physical Ledger test, independent audit or full binary reproducibility claim.
The legacy official Ledger WebHID transport is deprecated/unmaintained upstream;
separate SDK migration and hardware tests remain required. npm signatures and
zero reported vulnerabilities do not prove that upstream code is harmless.
The installer is unsigned; local malware can replace it. Donation-address
transactions can connect a pseudonym to other public or identified activity.
