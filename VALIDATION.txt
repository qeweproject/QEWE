QEWE 3.2.0-rc.3 — public preview validation scope

Source checks run dependency audit/signature verification, vendor rebuild/checksums, privacy-pattern checks, unit tests and DOM/worker tests.
The release workflow builds Windows x64, Ubuntu amd64, Mac arm64 and Mac x64 natively, then compares installed application bytes, icons and runtime protections to the exact source. All four jobs must succeed before a draft distribution is published.
Release files include checksums, source metadata, a dependency SBOM and build provenance. Provenance is verified before publication. Consult the actual tagged workflow run for results; this file is not an audit certificate.

Public disposable wallets and mocked RPC/device responses are used by tests. A simulated interface demonstration is not proof of hardware interaction. Physical wallet testing, a complete OS execution matrix, independent audit and independent bit-for-bit installer reproducibility have not been performed by this build environment.
Windows lacks an Authenticode publisher signature; Mac signatures are ad hoc without Apple notarization. Do not disable sandbox or OS security to make a preview work.
