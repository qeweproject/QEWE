## Announcement draft

**QEWE: an open-source Ethereum address explorer, built around Ledger**

QEWE checks ETH/ERC20 balances across common Ledger/MEW/BIP44 derivation paths and optionally native balances on other EVM networks. It also supports an explicit offline transaction-file signing workflow. Online signing is Ledger-only; Trezor/BitBox02 address reads are experimental.

The first public preview is available for Windows x64, Ubuntu amd64 and Mac Intel/Apple Silicon. Source code, checksums, dependency inventory and GitHub build provenance are public. It is not independently audited and the build environment has not tested physical devices. Windows is not Authenticode-signed and Mac builds are not notarized. Use public addresses or disposable wallets first; never enter a Ledger recovery phrase into a computer application.
